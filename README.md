📌 LecturePin
Never Miss a Class Again
LecturePin is an AI-powered university lecture schedule alert web app built for students who struggle with poor network coverage. When a lecture schedule changes, every registered student gets notified instantly — even with low signal.

🎯 The Problem
As a Software Engineering undergraduate in Sri Lanka, I constantly miss lecture schedule changes because:

Schedule updates get buried in WhatsApp group chats
Poor network coverage means missing critical notifications
No reliable way to get direct alerts about schedule changes

💡 The Solution
LecturePin delivers instant schedule change alerts directly to every registered student — cutting through group chat noise and working even in low connectivity areas.

✨ Features

🔔 Instant Alerts — Notified the moment a schedule changes
📅 Schedule Dashboard — View all current schedule changes
👨‍🎓 Student Registration — Register once with name and phone number
👨‍💼 Admin Dashboard — Post schedule changes to all students at once
📵 Low Connectivity Support — Works even with poor network coverage


🛠️ Built With

⚡ v0 by Vercel — AI powered UI generation
🚀 Vercel — Deployment and hosting
🤖 Cursor — AI assisted coding
⚛️ Next.js + React — Frontend framework
🎨 Tailwind CSS — Styling


🚀 Live Demo
👉 https://v0-lecturepin-web-app.vercel.app/

📱 How It Works

Student registers with name and phone number
Admin posts a schedule change with subject, old time, new time and date
All registered students get notified instantly at the same time
